## Procedure for obtaining the contents in the Hard-Disk

* We need 20 TB ( 5TB + 5TB + 5TB + 5TB ) external hard-disk for copying web and video courses till date at no cost.
* Institution shall send the hard-disk through courier or they can hand-over in person.
* The institution or organization/companie's should submit hard copies of the following documents :-
  * A Letter (Printed on College Letterpad) requesting for NPTEL Contents. The letter should contain the contact details of the institute's/companie's representative, along with the serial numbers of the HDDs. Download the [Sample Request Letter](https://drive.google.com/file/d/1RlkqyW5oXTzeZqDnnSBtbCuLzMnCXuxH/view)
  * Copyright form, duly attested by the Head of the institution. Click here for downloading the [NPTEL Copyright Form](https://drive.google.com/file/d/1Fn9_x_TwiGHuG479p6BuQmd1ptKqqF_m/view)
* If you are Company/Industry who has already signed an MoU with NPTEL, the letter would not be required.
* The expected time for the copying process to complete is one month.
* The authorization letter should be sent to [nptel-harddisk@nptel.iitm.ac.in](mailto:nptel-harddisk@nptel.iitm.ac.in) during HDD pickup mentioning the details of the person collecting the hard-disk and the person should carry any ID- proof along with them.
* To obtain the NPTEL Videos and Web Contents [Click Here](https://docs.google.com/a/nptel.iitm.ac.in/forms/d/e/1FAIpQLScx_67oNxqSqlCSwA5Wtp23cthZBgDRotDPbsVVjo3J3AYPPw/viewform?c=0&w=1)
* In case of any harddisk related issue please fill the google form [Click Here](https://docs.google.com/forms/d/1Gxw185VYiUMhdNYPd0yBAWxwAaco1iGq51fBFlw0YE0/viewform?edit_requested=true)

## Accessing NPTEL

### Course Size List

> **[TABLE · data]** Size of the course content per discipline, loaded from an API. Columns: S.NO | DISCIPLINE NAME | SIZE (GB). About 28 rows, numbered from 1, one per discipline (Aerospace Engineering, Agriculture, ... Textile Engineering), in the order the API returns them. The column heading row stays fixed while scrolling. No search, filter or pagination; rows are not clickable.
