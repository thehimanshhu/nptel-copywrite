### NOC Exam results

> **[TABLE · data]** One row per run of the course for this learner. Columns depend on the course type:
>
> * Normal courses: Timeline | Name | Course Name | Assignment (25) | Exam (75) | Final (100) | Action
> * Courses with an unproctored programming exam: Timeline | Name | Course Name | Assignment (25) | Unproctored programming exam (25) | Exam (50) | Final (100) | Action (for course noc22-cs42 the fifth heading reads "Programming Assignment (25)")
> * BCBR courses: Timeline | Name | Course Name | Assignment (100) | Exam (100) | Action (no Final column)
>
> Action cell: when the learner is eligible, "LinkedIn" and "Facebook" share links (new tab; only for runs numbered 40 or above), then **Download E-Certificate** (new tab), then, when an FDP certificate exists, **Download FDP certificate** with its own LinkedIn and Facebook share links. Otherwise the text "Not eligible".

### Assignment Scores:

> **[TABLE · data]** Single row of weekly assignment scores. Column headings A1, A2, … up to the number of assignments in the course; the cell under each heading holds that week's score. When there is no data the text "No assignment data available" is shown instead.
