> **[BREADCRUMB]** Grey header band with the trail "NPTEL > Local Chapter" (the NPTEL link goes to the page itself) above the page heading.

## College Statistics

> **[COLLEGE CARD · data]** One card for the local chapter, loaded from the college record. Upper half: college logo (IMAGE, placeholder picture if missing), college name as a heading, college address, then the label "Url: " followed by the college website as a link (opens in a new tab). Lower half: SPOC photo (IMAGE, placeholder picture if missing) and four labelled lines, with the values filled from the record: "SPOC Name - " SPOC NAME; "Designation - " SPOC DESIGNATION; "Partnering since - " DATE (YYYY-MM-DD); "College Id - " COLLEGE ID, then " Institute Type - " INSTITUTE TYPE. An "spoc onboard badge" IMAGE is shown on the card only when the SPOC is marked as onboarded.

> **[GREETING · data]** One sentence: "NPTEL is very happy to be associated with COLLEGE NAME institute and its students. We are thankful to SPOC NAME for being a pillar of support in NPTEL initiatives." (college name and SPOC name come from the college record.)

> **[BANNER · data]** Yellow and grey banner, shown only when the college has a rating for the latest rated semester. One line, starting with that semester (for example "Jan-Apr 2026: ") followed by one of these sentences depending on the rating: for A, AA or AAA, "CONGRATS! You are one of the top 200 Local Chapters." then a line break and "Your college is hereby recognized as an ACTIVE Local Chapter."; for Active, "Your college is hereby recognized as an ACTIVE Local Chapter."; for Active - Aspirants, Active - Contenders or Active - Prospects, "Your college is hereby recognized as an RATING IN CAPITALS Local Chapter."

> **[TABLE · data]** Semester-by-semester statistics for the college, newest first (about 24 rows for a long-standing chapter, from Jan-June 2014 to the latest semester); semesters with no learners present are left out. Empty counts show "-". The Course Run cell is a link to https://nptel.ac.in/localchapter/statistics/COLLEGE ID/SEMESTER CODE (opens in a new tab). The NPTEL Stars cell is a "Details" link to https://nptel.ac.in/localchapter/lcstars/COLLEGE ID/SEMESTER CODE (opens in a new tab) for semesters from Jul-Dec 2019 onward (except Jan-Apr 2019) that have star data, and "-" otherwise. Column headings:
