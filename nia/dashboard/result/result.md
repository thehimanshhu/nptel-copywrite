# {result window label}

> **[GRID · data]** Four summary boxes: Learners | Courses | Toppers | Avg final score (a number under each label).

> **[CALLOUT BOX]** Shown instead of the table when there is no data for the run.
> **Exam results are not available for this run.**
>
> Try selecting another run from the navigation menu.

> **[FORM]** Search box (placeholder "Search course, learner or organization"); "Rows per page" dropdown (5, 10, 25, 50); **Export CSV** *(button)*.

> **[TABLE · data]** Exam results of the organisation's learners in the run. Columns: (row checkbox, with a select-all checkbox in the heading) | S. No | Course ID | Course name | Roll number | Name | Email | DOB | Role | Organization | Assignment score | Unproctored score | Exam score | Final score | Certificate type | Topper. Every column heading is a button that sorts the table. Empty DOB, role, organization or topper show "—". Certificate type is derived from the final score (for example "Successfully completed", or "No Certificate"). Topper is one of "Topper of this course", "Topper of 1% in this course", "Topper of 2% in this course", "Topper of 5% in this course". Contains personal data, so rows are not reproduced. When no row matches the search, the table shows "No exam results match the current filters."

> **[PAGINATION]** Text "Showing {start}-{end} of {total} exam records"; when rows are ticked, "{n} row(s) selected" with a **Clear** button; page buttons First | Previous | page numbers (with …) | Next | Last.
