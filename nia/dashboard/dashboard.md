> **[NAV BAR]** Bar shared by all four dashboard pages. NPTEL logo ("NPTEL", links to https://nptel.ac.in/) on the left; centre links: **[Home](https://nptel.ac.in/nia/dashboard)** | **Enrollment** (dropdown) | **Registration** (dropdown) | **Exam Results** (dropdown); **[Logout](https://nptel.ac.in/auth/signout)** *(button)* on the right. Each dropdown lists one entry per past run (a period label such as "Jan-Apr 2021"), linking to the matching enrollment, registration or result page; when a dropdown has none it shows "No runs available". On small screens the links collapse into a menu button.

> **[CALLOUT BOX]** Shown to administrators only, above the profile.
> **Admin view:** You are viewing this dashboard as {company email}
>
